Политика конфиденциальности

Настоящая Политика конфиденциальности персональных данных (далее — Политика) действует в отношении всей информации, которую сайт может получить о Пользователе во время использования сайта.

1. Общие положения

1.1. Использование сайта означает безоговорочное согласие Пользователя с настоящей Политикой и указанными в ней условиями обработки его персональной информации.

1.2. В случае несогласия с условиями Политики Пользователь должен прекратить использование сайта.

2. Персональные данные Пользователя

2.1. В рамках настоящей Политики под персональной информацией Пользователя понимаются:

  • Имя;
  • Контактные данные (телефон, email, ник в мессенджере);
  • Текст сообщения, который Пользователь оставляет добровольно;
  • Иные данные, предоставленные Пользователем добровольно.

3. Цели обработки персональных данных

3.1. Персональные данные Пользователя обрабатываются в целях:

  • Связи с Пользователем, включая направление уведомлений и ответов на запросы;
  • Оказания услуг и обработки заявок;
  • Улучшения качества работы сайта.

4. Условия обработки персональных данных

4.1. Обработка персональных данных Пользователя осуществляется без ограничения срока, любым законным способом.

4.2. Персональные данные Пользователя не передаются третьим лицам, за исключением случаев, предусмотренных законодательством.

5. Хранение и защита данных

5.1. Данные хранятся не дольше, чем это необходимо для связи с Пользователем.

5.2. Применяются разумные меры защиты от несанкционированного доступа к персональным данным.

6. Права Пользователя

6.1. Пользователь вправе запросить удаление своих данных, направив обращение через контактные данные, указанные на сайте.

6.2. Пользователь вправе отозвать согласие на обработку персональных данных.

7. Изменения в Политике

7.1. Политика может обновляться. Актуальная версия всегда размещена на этой странице.

7.2. Продолжение использования сайта после внесения изменений означает согласие Пользователя с новой редакцией Политики.

8. Контакты

8.1. По всем вопросам, связанным с настоящей Политикой, Пользователь может обратиться через контактные данные, указанные на главной странице сайта.
